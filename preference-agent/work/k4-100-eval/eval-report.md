## 结果解释

- 全部预测 non-pushback，可在完整 93 条上得到 73/93 = 78.5% accuracy；四种方法均低于该正确率。这个参考策略的 pushback F1 为 0，不能仅凭 accuracy 选择模型。
- 同样 89 条上，B3 的 AUROC、AUPRC、Brier 最好；Agent 没有超过 BM25。
- Agent 的 AUROC 接近 0.5，排序区分能力弱；各方法平均预测的 pushback 概率高于实际正例比例，存在整体高估。
- 在 90 个完整配对上，no_memory − agent Brier 差为 0.0546，repo bootstrap 95% CI 为 [0.015760188563800206, 0.09570641176470585]，支持 Agent 相比同框架无记忆降低概率误差。
- 相同 89 条上，B3 − Agent Brier 差的 95% CI 包含 0；尚不能证明两者有稳定差异。
- 这批随机、不平衡的新样本表现弱于上一批平衡 30 条；不能将两批正确率直接当作同一评估比较。
