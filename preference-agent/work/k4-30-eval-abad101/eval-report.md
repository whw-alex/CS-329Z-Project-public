偏好记忆 agent 的概率误差低于无记忆；相同 29 条上，agent 与 BM25 很接近。repo bootstrap 的差值置信区间均包含 0，本批结果不足以证明稳定提升。

全 30 条 no_memory − agent 的 Brier 差为 0.0296，95% repo bootstrap CI = [-0.05437058181818179, 0.0981467393509128]。

## 有效性与复现

- B3 case-0010 引用了不在检索结果中的事件，校验失败；保留原始失败，未重试。
- Agent 30/30 首次预测通过校验；17 条拥有 active rule，9 条引用历史。
- 3 条没有可用的历史反馈：case-0004、0015、0027；汇总 JSON 另含仅有历史的子集指标。
- 110 个离线测试通过；修复 evaluate.py 的 pandas 只读数组兼容问题。
- 运行日志出现一次模型输出截断警告；对应运行最终通过校验。
- 已保存的 agent 配对流程合计 363 次调用，baseline 共 60 次；不包含切换并行时中断流程尚未保存的调用，因此不是实际计费总数。
- 为并行按 repo 分为 3 组，每组上限 200 次、每 case 上限 60 次；同 repo 共用历史记忆。
